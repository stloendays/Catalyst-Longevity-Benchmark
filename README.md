# 催化剂寿命数据分析与实验辅助系统

**Catalyst Longevity Research** 是本项目的工程名称。当前主要软件产品是一套 Windows 原生桌面应用，用于催化剂长期稳定性实验的数据检查、寿命分析、条件核对、同时间比较、后续实验辅助、公开参考查询、资料整理和 PDF 报告输出。

核心桌面程序采用 **C++20 + Qt 6 + SQLite**，实验分析和内置参考查询可以在本地完成，不依赖浏览器和外部 AI 服务。

## 核心使用流程

```text
内置数据集 / CSV / Excel
          ↓
数据质量检查
          ↓
实验条件检查
          ↓
长期性能与 T95 / T90 / T80
          ↓
同时间催化剂比较
          ↓
公开实验窗口匹配
          ↓
下一轮实验建议 + 可执行性 + 依据
          ↓
资料整理与人工确认
          ↓
本地项目保存 / PDF 报告
```

## 内置数据集

桌面程序原生内置 5 组模拟数据，用户无需准备外部文件即可体验完整分析流程。

| 数据集 | 主要展示功能 |
| --- | --- |
| 长期稳定性对比 | 多催化剂长期曲线、保持率、T90、同时间比较 |
| T90 区间定位 | 区间寿命表达与加密采样建议 |
| 长周期寿命下限 | 测试结束仍未达到 T90 时的寿命下限和分阶段延长建议 |
| 实验条件差异检查 | 条件不一致识别与直接排名阻止 |
| 数据质量检查 | 重复时间点、条件缺失、条件变化和完整度评分 |

内置数据明确标记为**模拟数据**，用于软件功能演示、培训和流程验证，不作为真实实验结论。

## 内置公开参考库

桌面程序同时编译了一组小型公开事实快照，与上述模拟数据完全分层。

当前包含：

- PubChem：甲烷、二氧化碳、氢气、一氧化碳和水的 CID、分子式、分子量及来源地址；
- Zhou 等 ChemCatChem 论文 DOI `10.1002/cctc.201500379` 的约 100 h、700 ℃、CH4/CO2=1:1 DRM 长期测试窗口；
- He 等 Processes 论文 DOI `10.3390/pr9040706` 的 700 ℃、近常压、GHSV 24000 mL g^-1 h^-1 条件，以及 50 h / 200 h 稳定性测试窗口。

参考库只保存事实性元数据和简短实验条件摘要，不复制论文全文或图表。系统只有在当前用户数据能识别出相近反应体系，并且温度、空速、压力、进料和催化剂体系达到一定相关度时，才把公开实验窗口作为建议时长的量级参照；匹配不足时不会强行套用。

## 数据导入

支持：

- CSV `.csv`
- Excel `.xlsx`
- 内置数据集

最少需要三列：

| 催化剂 | 时间 | 性能 |
| --- | ---: | ---: |
| Catalyst A | 0 | 82 |
| Catalyst A | 20 | 78 |
| Catalyst A | 50 | 73 |
| Catalyst B | 0 | 76 |
| Catalyst B | 20 | 74 |
| Catalyst B | 50 | 72 |

为了进行可靠的跨催化剂比较，建议同时提供温度、GHSV/WHSV、压力、进料比、指标和数据来源。

## 数据检查

载入数据后自动检查：

- 重复时间点；
- 无效和异常性能值；
- 实验条件缺失；
- 同一催化剂测试过程中的条件变化；
- 不同催化剂之间的条件差异。

系统给出数据完整度评分以及逐条处理建议。

## 寿命分析

桌面程序计算并展示：

- 初始性能；
- 最新性能；
- 性能保持率；
- T95；
- T90；
- T80；
- 长期性能曲线。

阈值只被两个实际观测点夹住时，系统保留区间表达；测试结束仍未达到阈值时，系统保留寿命下限。不会把插值结果冒充为直接测得的精确寿命。

## 条件检查与同时间比较

系统在跨催化剂比较前检查已提供的温度、空速、压力和进料条件。

- 条件一致：允许继续比较；
- 条件缺失：结果仅作参考；
- 条件明确不一致：停止输出直接领先结论。

同时间比较使用两个催化剂最近的共同实际观测时间，而不是直接比较各自最后一个数据点。

## 实验建议

实验建议不再只输出一个“建议做到多少小时”的数值，而是尽量转化为可以执行的下一步：

- 时间点过少时，优先在现有最大采样空档内补关键时间点；
- T90 尚未达到时，分阶段延长测试并保留中间采样点，到达阶段终点后重新判断；
- T90 落在两个时间点之间时，优先只补一个区间中部采样点以缩小寿命区间；
- 首次观测已经达到 T90 时，保留 0 h 基线并提前首个采样时间；
- 实验条件不足时，先补齐温度、空速、压力和进料记录；
- 两个催化剂在共同时间的相对差异很小时，优先建议独立重复验证，而不是直接判优；
- 相近公开实验窗口只用于校验测试时长量级，不自动修改用户实验条件。

每条建议显示 **可执行性评分、原因、下一步动作和依据**。可执行性考虑数据完整度、实验条件一致性、建议跨度以及公开实验窗口相关度。该评分不是设备安全认证，反应器温压上限、气路安全、装填量和实验室 SOP 仍由实验人员确认。

## 资料整理

资料页支持带文本层的 PDF、TXT、Markdown、CSV 和 TSV，可识别 DOI、温度、测试时长、转化率等候选信息。

资料可以关联到具体催化剂和实验时间点，并由用户人工确认。未确认资料不会自动修改实验数据或进入受控 AI 资料范围。

## 本地项目与报告

项目可保存为 `.clrproj` 本地文件，持续保存实验数据、实验条件、资料关联和确认状态。

PDF 报告可包含：

- 数据检查；
- 条件检查；
- 寿命摘要；
- 同时间比较；
- 实验建议及可执行性；
- 公开参考库和当前匹配结果；
- 资料来源和确认状态。

## 自驱动实验室接口预留

原生桌面程序启动时会同时准备一组本机集成接口，为后续闭环实验编排和仪器适配预留稳定通信边界：

| 默认端口 | 协议 | 用途 |
| --- | --- | --- |
| `49321` | HTTP / JSON | 控制、能力发现、任务与结果包入口 |
| `49322` | TCP / JSON Lines | 长连接事件流 |
| `49323` | TCP / JSON Lines | 仪器适配器遥测入口 |

默认只监听 `127.0.0.1`，不会主动暴露到局域网。需要跨电脑接入时可以显式绑定 `0.0.0.0`，但此时强制要求至少 24 字符的访问令牌。当前版本明确保持 `hardware_actuation=false`：可以测试任务、结果、事件和仪器遥测协议，但不会因为收到网络请求而直接操作真实反应器或仪器。

控制端口提供 `/v1/health`、`/v1/capabilities`、本机 `/v1/pairing`、受认证的 `/v1/state`、`/v1/jobs`、`/v1/results` 和 `/v1/events`。接口合同见 `integration/sdl_gateway.openapi.yaml`，完整说明见 `docs/SELF_DRIVING_LAB_GATEWAY_CN.md`。

## 原生桌面构建

原生桌面源码位于：

```text
native/qt/
```

主要依赖：

- Qt 6 Widgets
- Qt SQL / SQLite
- Qt PDF
- Qt Network
- QXlsx

使用 CMake 构建：

```bash
cmake -S native/qt -B build-qt
cmake --build build-qt --config Release
```

Windows 构建产物使用工程文件名 `Catalyst Longevity Research.exe`，运行后的窗口和文档使用中文产品名称。

## 研究与原型代码

仓库中仍保留 Python / Streamlit、外部数据库和 AI 分析等研究原型，用于算法验证和后续能力探索。这些模块与当前原生桌面软件并存，但登记材料应以已经稳定实现并通过原生构建测试的桌面功能为主。

## 关键原则

- 不虚构缺失实验点；
- 不把测试结束时间直接当成精确寿命；
- 不把稀疏观测之间的插值结果冒充为实测值；
- 条件明确不一致时停止直接排名；
- 资料与实验观测分开保存；
- 内置模拟数据与用户真实数据明确区分；
- 公开参考只用于校验，不覆盖用户实验事实；
- 网络接口默认仅本机监听，外部绑定必须显式认证；
- 网络任务不会绕过硬件安全状态机直接执行；
- 报告保留数据来源、建议依据和分析边界。
