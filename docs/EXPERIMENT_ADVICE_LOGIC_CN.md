# 实验建议与可执行性逻辑说明

本文件说明“分析 → 实验建议”模块如何从已有实验数据生成下一步计划。该模块的目标不是替代实验负责人，而是把“下一步做什么”拆成可检查、可执行、可追溯的动作。

## 1. 输入信息

实验建议只使用以下信息：

- 用户已经导入的真实观测时间点；
- T95 / T90 / T80 的实测区间或寿命下限；
- 已填写的温度、GHSV/WHSV、压力和进料条件；
- 当前实际采样间隔；
- 用户可选填写的实验排期约束；
- 与当前反应上下文达到相关度门槛的公开实验窗口。

系统不会自动生成缺失实验点，也不会将公开论文中的性能值写入用户数据。

## 2. 用户可设置的排期约束

实验建议页提供两个可选参数：

### 单阶段最多追加

表示相对于当前最长测试时间，一个建议阶段最多继续增加多少小时。

例如当前测试到 80 h，用户设置“单阶段最多追加 24 h”，则即使自动规则或公开文献量级提示下一目标可到 120 h，系统也会优先把下一阶段限制在不超过约 104 h，再到阶段终点重新判断。

设置为 0 时采用自动规则。

### 最小采样间隔

表示实验设备、人员排期或分析频率能够执行的最小时间间隔。

当 T90 已被限制在一个窄区间，而用户设置的最小采样间隔已经不小于这个区间宽度时，系统不会继续给出一个实际上无法执行的“中点补样”，而会提示先确认采样能力。

设置为 0 时采用自动时间刻度。

上述两个值属于**实验排期约束**，不是设备安全参数，也不代表反应器允许的温度、压力或气体安全上限。

## 3. 不同寿命状态的建议逻辑

### T90 尚未达到

系统先根据当前最长时间和既有采样间隔生成数据驱动的下一阶段终点，然后：

1. 限制一次延长幅度，避免直接无限外推；
2. 若用户设置“单阶段最多追加”，进一步受该上限限制；
3. 尽可能保留一个阶段中间采样点；
4. 到达阶段终点后重新判断是否仍高于 T90；
5. 只有公开实验窗口与当前反应体系、温度、空速、压力或进料条件达到相关度门槛时，才用公开时长校验建议量级。

### T90 位于两个时间点之间

优先建议只增加一个区间中部时间点，以最低额外实验成本缩小 T90 区间。若用户设置的最小采样间隔已经大于该区间可细化尺度，系统改为提示先确认采样能力。

### 第一次观测已达到 T90

保留 0 h 基线，并建议将首个非零采样点提前，而不是把当前首次观测时间当作精确 T90。

### 时间点不足

当单个催化剂少于 3 个观测点时，优先在当前时间序列最大的采样空档中补关键点，而不是直接追加很长的终点测试。

## 4. 条件优先级

若不同催化剂之间温度、空速、压力或进料条件明确不一致，系统首先给出“统一比较条件”的建议。

此时延长寿命测试不会自动恢复跨催化剂可比性，因此条件问题的优先级高于“谁领先”和“再做多少小时”。

## 5. 小差异处理

若两个催化剂在最近共同实测时间点的相对性能差异不超过约 3%，系统优先提示进行独立重复验证，而不直接将小幅数值差解释为真实优劣。

该规则的作用是避免实验波动、样品差异或分析噪声被误认为稳定的排名差异。

## 6. 公开参考如何参与

当前公开参考包含 PubChem 组分基础事实，以及 Ni/Al2O3 甲烷干重整公开论文中的实验条件和 50 h、100 h、200 h 等长期测试窗口。

公开实验窗口参与建议前需要先通过上下文相关度匹配。匹配考察：

- 是否能识别为相近反应体系；
- 温度差异；
- GHSV 差异；
- 压力差异；
- 进料比例；
- 催化剂名称是否与 Ni / Al2O3 体系相符。

公开文献只用于回答“这个建议时长是否处于已有同类研究采用过的量级”，不会回答“用户必须照搬这篇论文的条件”。

## 7. 可执行性评分

每条建议生成 0–100 的可执行性评分。当前评分主要扣分项包括：

- 实验条件字段缺失；
- 同一催化剂测试期间条件发生变化；
- 时间点过少；
- 跨催化剂条件冲突；
- 一次建议延长跨度过大。

若存在足够接近的公开实验窗口，可作为量级参照增加少量置信支持。

界面采用“较高 / 中等 / 需确认”三个文字等级显示，同时保留数值分数和建议依据。

## 8. 使用边界

可执行性评分不是安全评分，也不是实验成功概率。

实际执行前仍需要实验人员确认：

- 反应器允许温度和压力范围；
- 气体与尾气处理要求；
- 催化剂装填量；
- 分析仪器能力；
- 实验室安全管理制度和 SOP；
- 人员值守和设备连续运行条件。

系统负责把数据分析结果转化为更具体的实验计划候选，并明确显示生成依据；最终实验方案仍由实际研究人员批准。
