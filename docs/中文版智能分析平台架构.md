# 中文版催化剂智能分析平台架构

## 产品目标

平台优先服务不希望先学习科研数据规范的用户。用户可以直接提供实验表格、论文、报告、DOI 或数据库检索条件，系统负责把资料转换成可分析、可追溯的证据。

## 用户入口

```text
A. 长期表现分析
   CSV / Excel / 直接编辑表格

B. 资料分析
   PDF / TXT / Markdown / 文本

C. 外部数据库检索
   DOI / 文献关键词 / 催化反应条件
```

## 当前工作流

```text
用户资料
  ↓
格式识别
  ↓
保守信息提取
  ├─ DOI
  ├─ 温度
  ├─ 测试时长
  ├─ 性能候选值
  └─ 机制/稳定性关键词
  ↓
Evidence Graph
  ↓
外部数据库校验
  ├─ Crossref
  └─ Catalysis-Hub
  ↓
结构化 TOS 数据
  ↓
Longevity / Ranking Engine
  ↓
中文结论
  ↓
Advisor
  ├─ 运行时长相关选材建议
  ├─ 反超区间加密测试建议
  ├─ 可比性提醒
  └─ 来源完整性提醒
```

## Evidence Graph 设计

每个数据点或结论需要保留至少以下信息：

| 层 | 示例 |
|---|---|
| Document | 用户上传的论文 PDF |
| Identifier | DOI |
| Condition | 700 °C、100 h |
| Measurement candidate | CH4 conversion 80% |
| Binding | Catalyst A @ 100 h @ 700 °C |
| External metadata | Crossref paper identity |
| Derived analysis | retention、t90、ranking |
| Conclusion | B 在长时运行下超过 A |
| Recommendation | 在 20–50 h 加密测试 |

候选值不等于正式 measurement。必须完成 Catalyst + Time + Condition 绑定后才能进入长期排名。

## 外部数据库优先级

### 已接入

1. Crossref
   - DOI 精确查询
   - 文献关键词搜索
   - 标题、作者、期刊、年份等元数据

2. Catalysis-Hub
   - reactants / products 检索
   - reaction energy
   - activation energy
   - chemical composition

### 下一步

3. Semantic Scholar
   - 相关论文
   - citation neighborhood
   - author / paper graph

4. Materials Project
   - bulk/material identity
   - thermodynamics
   - surface/material background

5. PubChem
   - precursor / promoter / molecular entity normalization

## 分析能力升级原则

分析能力不依赖单一语言模型直接阅读全文后自由回答，而采用分层工具：

```text
资料解析
  ↓
条件匹配
  ↓
数值绑定
  ↓
长期表现计算
  ↓
证据审计
  ↓
建议生成
```

后续加入 AI 模型时，AI 负责：

- 识别用户意图；
- 组织资料；
- 提出候选解释；
- 调用确定性的分析工具；
- 生成用户可读建议。

AI 不负责擅自创造实验点、覆盖 source conflict 或把无法比较的条件强行排序。

## 后续重点

优先级 1：PDF 中的表格/条件/曲线提取流程。

优先级 2：实验条件匹配器，避免把不同温度、GHSV、feed ratio 的催化剂直接排名。

优先级 3：把 Evidence Graph 延伸到正式 TOS measurement 和 analysis conclusion。

优先级 4：连接 Semantic Scholar / Materials Project / PubChem。

优先级 5：加入可配置 AI Analyst，通过 API 调用现有 deterministic tools，并增加独立 Evidence Critic。
