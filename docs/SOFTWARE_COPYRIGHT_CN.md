# 催化剂寿命分析与实验决策软件 V1.0

> 软著材料准备草案。软件内部英文工程名仍可保留 `Catalyst Longevity Research`，对外登记建议使用中文全称。

## 一、软件定位

本软件面向高校实验室、科研院所、催化剂研发团队及化工企业研发人员，用于整理催化剂长期稳定性实验数据，检查实验数据质量，分析寿命指标，在实验条件允许的情况下进行同时间对比，并根据当前观测结果给出下一轮实验建议。软件同时支持论文资料整理、催化剂与时间点关联、人工确认和 PDF 报告导出。

软件采用本地 Windows 桌面程序方式运行，实验数据、项目资料和人工确认状态均可保存到本地项目文件中，适合科研项目持续迭代和结果复查。

## 二、主要应用价值

### 1. 减少 Excel 手工整理和重复核对

软件支持直接导入 CSV 和 Excel 数据，并自动完成催化剂分组、时间排序、性能保持率和寿命指标计算。数据导入后可自动检查重复时间点、异常数值、实验条件缺失和同一催化剂内部条件变化，并生成明确的处理建议。

### 2. 避免不合理的跨催化剂排名

软件在比较不同催化剂前自动检查温度、空速、压力和进料条件。当实验条件明确不一致时，系统停止输出直接领先结论，避免把不同实验条件下的数据简单排序。

### 3. 将寿命分析直接转化为下一轮实验计划

软件对 T95、T90、T80 采用与实际观测一致的区间表达。当 T90 尚未达到时，可根据当前测试长度和采样间隔建议延长测试时间；当 T90 位于两个采样点之间时，可建议在区间中部增加采样点；当首次观测已经低于 T90 时，可建议提前首个采样时间。

因此软件不仅回答“当前结果是什么”，还进一步回答“下一轮实验应该怎么补”。

### 4. 提供条件受控的同时间比较

系统自动寻找两个催化剂最近的共同观测时间，显示双方性能值、差值和当前较高者。若实验条件不一致，则仅显示状态，不给出直接领先判断；实验条件未填写完整时，比较结果标记为“仅供参考”。

### 5. 将论文资料与实验对象建立可追溯关联

软件可读取带文本层的 PDF 以及 TXT、Markdown、CSV、TSV 等资料，提取 DOI、温度、测试时长、CH4 转化率等候选信息，并允许用户将资料条目关联到具体催化剂和时间点。只有经过人工确认的资料才进入 AI 可用资料区。

### 6. 形成可复查的本地科研项目

实验记录、资料条目、关联关系和确认状态可统一保存到 `.clrproj` 本地 SQLite 项目文件中。用户可以在后续实验完成后重新打开项目继续分析，不需要重新整理历史数据。

### 7. 一键输出分析报告

软件可将催化剂寿命结果、条件检查、资料审计信息等导出为 PDF 报告，便于组会讨论、实验记录归档、项目阶段总结和内部技术交流。

## 三、功能模块

### 1. 项目

- 新建项目
- 打开项目
- 保存项目
- 另存为项目
- 本地 SQLite 项目持久化

### 2. 首页

- 催化剂数量和数据点概览
- 最长测试时间
- 条件检查状态
- 当前领先催化剂
- T90 状态
- 资料状态
- 长期性能曲线
- 曲线悬停查看精确数据
- 单击催化剂曲线进行聚焦

### 3. 数据

- CSV 导入
- Excel `.xlsx` 导入
- 原始数据表查看
- 自动数据检查
- 数据完整度评分
- 重复时间点检查
- 异常性能值检查
- 实验条件缺失检查
- 同一催化剂条件变化检查

### 4. 资料

- PDF 文本层读取
- TXT / Markdown / CSV / TSV 资料读取
- DOI、温度、测试时长等信息识别
- 资料与催化剂关联
- 资料与时间点关联
- 人工确认 / 取消确认
- AI 可用资料预览

### 5. 分析

#### 寿命指标

- 保持率
- T95
- T90
- T80
- 左删失、区间和右删失状态保留

#### 同时间对比

- 自动寻找两个催化剂最近共同时间
- 显示双方性能值
- 计算差值
- 条件不一致时阻止直接判断

#### 实验建议

- 时间点不足提示
- T90 未达到时建议延长实验
- T90 位于区间时建议增加中间采样点
- 首次观测已低于 T90 时建议提前采样
- 实验条件缺失时提示补全记录

### 6. AI 助手

- 显示当前 AI 可用资料
- 未确认资料自动排除
- 为后续接入模型 API 保留受控输入边界
- 分析结果和资料来源可追溯

### 7. 设置

- 软件版本和技术信息
- 本地运行说明
- 数据格式和项目格式说明

## 四、典型使用流程

1. 新建一个催化剂研究项目。
2. 导入 CSV 或 Excel 长期实验数据。
3. 查看“数据检查”，处理重复记录和实验条件缺失。
4. 在首页查看长期性能曲线和总体状态。
5. 在“分析”中查看 T95 / T90 / T80。
6. 使用“同时间对比”比较不同催化剂。
7. 根据“实验建议”确定下一轮测试时长和采样点。
8. 在“资料”中导入论文，并关联到具体催化剂和时间。
9. 对资料完成确认后，可作为 AI 助手的输入资料。
10. 保存项目并导出 PDF 分析报告。

## 六、技术实现概要

- 开发语言：C++20
- GUI 框架：Qt 6 Widgets
- 本地数据库：SQLite
- Excel 读取：QXlsx
- PDF 读取：Qt PDF
- PDF 报告：QPdfWriter / QTextDocument
- 运行方式：Windows 原生桌面应用
- 项目文件：`.clrproj`
- 数据输入：`.csv`、`.xlsx`
- 资料输入：`.pdf`、`.txt`、`.md`、`.csv`、`.tsv`
