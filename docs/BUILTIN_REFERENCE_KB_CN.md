# 内置公开参考库说明

本系统内置一组小型、可离线读取的公开参考快照，用于两个目的：

1. 核对常见反应组分的基础身份信息；
2. 判断自动生成的寿命测试时长是否处于公开同类研究已经采用过的量级。

参考库不会覆盖用户实验数据，也不会把文献条件自动改写成用户的实验条件。

- 温度：700 ℃
- 压力：0.1 MPa / 近常压
- GHSV：24000 mL g^-1 h^-1
- 文中包含 50 h 稳定性筛选，并对 Ni/Al2O3-750 报告 200 h 长周期测试
- 200 h 测试进料：CH4:CO2:Ar = 1:1:3

系统把同一论文的 50 h 与 200 h 作为两个不同用途的实验窗口：阶段性筛选和长周期验证。

## 3. 如何参与实验建议

公开实验窗口只在当前数据能够识别出相近反应上下文时参与建议。匹配考虑：

- 是否可识别为甲烷干重整上下文；
- 温度差；
- GHSV 差异；
- 压力差异；
- 进料比例；
- 催化剂名称是否显示 Ni / Al2O3 相关体系。

系统生成 0–100 的“相关度”，相关度不足时不会强行套用文献时长。

即使匹配度较高，文献只用于校验建议的时间量级。例如当前数据支持先延长到约 100 h，而公开同类研究也存在约 100 h 的长期测试，软件可以把该论文列为参考依据；它不会因此把用户的温度、GHSV 或进料自动改成论文条件。

## 4. 实验建议的可执行性评分

“可执行性”根据当前数据计算，主要考虑：

- 时间点是否足够；
- 温度、空速、压力、进料条件是否完整；
- 同一催化剂测试过程中条件是否发生变化；
- 不同催化剂之间是否存在条件冲突；
- 建议延长的时间跨度是否过大；
- 是否存在足够接近的公开实验窗口作为量级参照。

该评分不是实验安全评分。反应器温压上限、气路安全、催化剂装填量、分析仪器能力和实验室 SOP 仍必须由实际实验人员确认。
