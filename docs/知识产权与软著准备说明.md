# 知识产权与软著准备说明

本文件用于记录当前软件产品化过程中与知识产权、软件著作权准备相关的工程边界，方便后续继续开发、整理材料或交接。

## 1. 当前定位

当前仓库首先是一个可运行的软件系统与科研验证工程。

项目正在按“未来可用于软件著作权材料整理”的方向持续完善，但目前不应对外表述为：

- 已获得软件著作权；
- 已申请专利；
- 已获得专利；
- 算法思想本身已受到专利保护。

如果后续确实启动专利申请，应另行开展 prior-art 检索、发明人/权属确认、技术方案提炼、权利要求撰写与申请策略，不与本文件混为一体。

## 2. 软件产品边界

当前软件产品可描述为：

> 面向催化剂长期表现、稳定性资料和多源科学证据的智能分析平台。用户可提供实验数据、论文资料、DOI 或外部数据库信息，系统对实验条件、性能随时间变化、证据来源和不确定性进行分析，并输出中文结论、风险提示与下一步建议。

核心用户流程：

```text
实验数据 / PDF / DOI / 外部数据库
        ↓
资料识别与证据结构化
        ↓
条件可比性审计
        ↓
长期表现分析
        ↓
Evidence Graph / Evidence Packet
        ↓
AI Analyst
        ↓
Evidence Critic
        ↓
结论 + 风险 + 下一步建议
```

## 3. 当前可识别的软件模块

### 数据导入与校验

- 中文/英文列名兼容；
- CSV / Excel 数据输入；
- 时间序列与催化剂标识校验；
- 异常输入 fail-closed。

### 长期表现分析

- 初始性能；
- 最新性能；
- 性能保持率；
- t95 / t90 / t80；
- 删失状态；
- 动态排名；
- 排名反转区间；
- 累积表现/AUC；
- 下一步观测建议。

### 条件可比性检查

- 温度；
- GHSV；
- WHSV；
- 压力；
- 进料比；
- 反应类型。

明确条件不匹配时，可阻止直接优劣排名。

### 资料分析

- PDF / 文本提取；
- DOI；
- 温度；
- 测试时长；
- 性能候选值；
- 稳定性/失活/积碳/烧结等关键词；
- 原文证据片段；
- Evidence Graph。

### 外部数据库连接

当前包含：

- Crossref；
- Semantic Scholar；
- Catalysis-Hub；
- Materials Project；
- PubChem。

### AI 分析与审查

- Evidence Packet；
- deterministic precheck；
- AI Analyst；
- Evidence Critic；
- `approved / needs_review / blocked` 三种结果状态；
- Evidence ID 引用与审计导出。

### 用户界面

中文版 Streamlit multipage UI：

1. 长期表现分析；
2. 资料分析；
3. 外部数据库；
4. AI 智能分析。

共享统一 Design System、主题、状态提示和工作流导航。

## 6. 数据与来源边界

为避免知识产权和科研证据混乱，软件中必须持续区分：

```text
source_observed

digitized

candidate_requires_condition_binding

model_derived

external_context

synthetic_demo
```

不要把他人论文原始图表、长段文本或受限制数据直接作为软件自有数据重新发布。

用户上传的私有资料和公开知识库应保持逻辑分层。

## 7. 安全与权属注意事项

- API Key 不写入仓库。
- 用户上传的 unpublished data 默认不进入公共数据库。
- 仓库保持 private，除非所有者明确授权公开。
- 新增正式合作者后，应记录代码/数据贡献边界。
- 若软件纳入学校、导师、公司或资助项目，应在正式申请知识产权前核对相应 IP/职务成果条款。

## 8. 当前最值得继续开发的知识产权相关软件能力

从“完整软件产品”角度，下一步优先级为：

1. Workspace Dashboard；
2. Measurement Binder；
3. PDF/表格/图中数据到结构化 measurement 的绑定；
4. Scientific Tool Calling；
5. 用户项目持久化；
6. 可审计 HTML/PDF 报告；
7. 更完整的操作手册与界面截图；
8. 桌面打包。

Measurement Binder 的目标结构示例：

```text
Catalyst = Ni-0.16B/Al2O3
Metric = CH4 conversion
Value = 80.6 %
Time = 100 h
Temperature = 700 °C
GHSV = 18000
Source = Table S4
Evidence class = source_observed
```

只有完成催化剂、指标、时间、条件和来源绑定后的 measurement，才允许进入确定性比较。
