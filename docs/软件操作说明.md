# Catalyst Longevity Analyzer 软件操作说明

## 1. 软件名称

**Catalyst Longevity Analyzer｜催化剂长期表现分析系统**

## 2. 软件用途

本软件用于比较催化剂或其他材料在持续运行过程中的性能变化。

用户不需要先学习专门的统计方法，只需要提供“样品名称、时间、性能”数据，即可获得：

- 初始性能与最新性能；
- 性能保持率；
- 95%、90%、80% 性能保持情况；
- 催化剂之间是否发生领先顺序变化；
- 长时间运行曲线；
- 测试时长是否足以支持寿命判断；
- 可下载的汇总表、简明报告和完整数据。

软件当前主要用于催化剂稳定性和失活分析，也可用于其他“性能随时间下降或变化”的长期测试数据。

## 3. 主要功能

### 3.1 数据导入

支持：

- CSV 文件；
- Excel 文件；
- 网页中直接粘贴、输入和编辑数据；
- 中文或英文常用列名；
- 可选误差上下限；
- 可选数据来源和指标信息。

### 3.2 自动数据检查

导入后自动检查：

- 是否缺少必要字段；
- 是否存在空数据；
- 时间是否为负数；
- 同一催化剂是否存在重复时间点；
- 误差范围是否完整；
- 性能值是否位于声明的误差范围内。

检测到问题时，软件会给出提示并停止错误计算，而不是自动篡改用户数据。

### 3.3 长期表现分析

软件自动计算并展示：

- 每个催化剂的第一次观测值；
- 最后一次观测值；
- 最新测试时间；
- 性能保持百分比；
- 性能是否已经下降到初始值的 95%、90%、80%；
- 若下降发生在两个时间点之间，则显示该时间区间；
- 若测试结束仍未下降到阈值，则显示“至少超过当前测试时长”。

### 3.4 催化剂之间的比较

当两个催化剂存在足够的共同时间点时，软件自动判断：

- 谁在前期领先；
- 后期是否发生反超；
- 反超发生在哪两个观测时间之间；
- 数据是否不足以做出判断。

前台直接使用“领先”“反超”“暂时无法判断”等语言，不要求普通用户理解内部统计术语。

### 3.5 图形显示

浏览器界面自动绘制性能随时间变化的曲线，用于直观看到：

- 哪个催化剂初始表现更高；
- 哪个催化剂下降更快；
- 哪个催化剂长期保持得更好；
- 曲线是否发生交叉。

图中的连线只连接已有观测点，不会生成新的实验数据。

### 3.6 结果导出

支持下载：

- **CSV 汇总表**：适合 Excel、WPS、Origin 等继续处理；
- **Markdown 简明报告**：适合人工阅读、项目汇报和知识库记录；
- **JSON 完整结果**：适合程序、API、Agent 和自动化工作流。

## 4. 软件安装

推荐使用 Python 环境。

在软件目录中首次运行：

```bash
python -m pip install -r requirements-ui.txt
```

Windows 用户也可以直接双击：

`首次安装_Windows.bat`

安装完成后无需重复执行安装步骤。

## 5. 启动软件

### 5.1 通用启动

```bash
python launch.py
```

软件会启动本地网页界面。浏览器通常会自动打开。

### 5.2 Windows 一键启动

双击：

`启动软件_Windows.bat`

### 5.3 高级用户启动

也可以直接运行：

```bash
streamlit run app.py
```

## 6. 主界面说明

启动后主界面包含以下区域。

### 6.1 数据模板

页面顶部提供 **下载数据模板** 按钮。

用户可先下载模板，在 Excel 或 WPS 中填写后重新上传。

### 6.2 数据来源选择

提供两种方式：

1. **上传文件**；
2. **直接编辑数据**。

直接编辑模式会显示一组示例数据，用户可以删除、替换或增加行。

### 6.3 数据预览

分析前显示完整输入表，便于检查数据是否正确。

### 6.4 开始分析

点击 **开始分析** 后，软件自动完成计算。

分析成功后显示：

- 催化剂数量；
- 数据点数量；
- 最长测试时间；
- 发现的领先顺序变化数量。

## 7. 输入数据格式

### 7.1 最简单格式

只需要三列：

| 催化剂 | 时间 | 性能 |
|---|---:|---:|
| Catalyst A | 0 | 82 |
| Catalyst A | 20 | 70 |
| Catalyst A | 50 | 58 |
| Catalyst B | 0 | 76 |
| Catalyst B | 20 | 72 |
| Catalyst B | 50 | 69 |

### 7.2 支持的常用列名

催化剂名称可以使用：

- `催化剂`
- `样品`
- `catalyst`
- `catalyst_id`
- `sample`

时间可以使用：

- `时间`
- `运行时间`
- `time`
- `time_h`
- `TOS`

性能可以使用：

- `性能`
- `转化率`
- `活性`
- `performance`
- `conversion`
- `activity`
- `value`
- `tof`

### 7.3 可选列

还可以提供：

- `下限 / lower`
- `上限 / upper`
- `指标 / metric`
- `数据来源 / provenance_class`
- `paper_id`

普通分析不要求提供这些字段。

## 8. 结果页面说明

### 8.1 “结论”页面

用于快速阅读结果。

包括：

- 催化剂之间是否反超；
- 每个催化剂的初始值；
- 最新值；
- 性能保持率；
- 95%、90%、80% 保持情况。

### 8.2 “性能曲线”页面

显示不同催化剂随时间变化的性能曲线。

### 8.3 “寿命信息”页面

逐个催化剂显示：

- 测试到多少小时；
- 当前还保留多少性能；
- 是否已经达到 95%、90%、80% 阈值。

### 8.4 “下载报告”页面

提供：

- CSV 结果汇总；
- Markdown 简明报告；
- JSON 完整结果。

### 8.5 “专业详情”页面

该页面面向需要核查底层数据和计算状态的用户。

普通用户可以忽略此页面。

## 9. 如何理解“寿命还没有测到”

例如某催化剂测试到 100 小时，性能仍为初始值的 93%。

这时软件不会写“寿命 = 100 小时”，而会提示：

> 测试到 100 小时时仍高于初始表现的 90%。

这表示：

**90% 性能保持时间至少超过 100 小时，但真正的时间还没有被当前测试测到。**

这比直接把测试结束时间当成寿命更符合实际使用逻辑。

## 10. 如何理解“发生反超”

假设：

- 0 小时：A = 82，B = 76；
- 20 小时：A = 70，B = 72。

软件会显示：

> Catalyst A 起初领先，但在 0–20 小时之间由 Catalyst B 反超。

软件只说明反超发生在这两个已有观测点之间，不会自动声称具体发生在第 8.3 小时或第 10 小时。

## 12. 错误提示

常见错误包括：

### 缺少必要列

提示用户添加“催化剂、时间、性能”三类字段。

### 同一催化剂出现重复时间

例如同一催化剂出现两行 `20 h`，软件会要求用户检查数据。

### 时间为负数

时间必须为 0 或正数。

### 误差范围不完整

如果提供下限，则必须同时提供上限。

### 第一条性能为 0

软件无法计算相对于初始值的保持率，因此会停止并提示。

## 13. 数据处理原则

为了避免用户得到看似精确但实际错误的结果，软件保留以下规则：

1. 不自动生成缺失实验点；
2. 不把测试结束时间直接当成寿命；
3. 不把稀疏曲线交点自动写成精确反超时间；
4. 有误差范围时，保留不确定性信息；
5. 高级数据来源信息不会在分析过程中被丢弃。

这些规则在后台执行，普通用户不需要手动操作。
