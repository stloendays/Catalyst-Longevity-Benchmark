# 内置数据集说明

本系统自带 5 组内置模拟数据，用于软件功能演示、流程验证和教学。内置数据不作为真实实验结论，也不替代用户自己的实验数据。

| 数据集 | 主要用途 | 关键行为 |
| --- | --- | --- |
| 长期稳定性对比 | 多催化剂长期性能分析 | 曲线、保持率、T90、同时间对比 |
| T90 区间定位 | 采样点优化 | 保留区间寿命并给出加密采样建议 |
| 长周期寿命下限 | 长时间稳定性测试 | 展示测试结束仍未达到 T90 的寿命下限 |
| 实验条件差异检查 | 条件一致性检查 | 发现温度差异后停止直接排名 |
| 数据质量检查 | 数据质控 | 识别重复时间点、条件缺失和条件变化 |

内置数据集编译在原生桌面程序中，不需要单独下载。用户可在“首页”或“数据”页面点击“内置数据集”后选择数据集，载入后会进入与 CSV / Excel 导入数据完全相同的分析流程。
