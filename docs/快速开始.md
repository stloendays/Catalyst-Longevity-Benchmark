# 催化剂寿命数据分析与实验辅助系统 — 快速开始

本系统用于整理和分析催化剂长期稳定性实验数据。用户可以直接使用内置数据集熟悉完整流程，也可以导入自己的 CSV 或 Excel 数据。

系统为 Windows 原生桌面应用，主要分析工作在本地完成，不需要通过浏览器操作。

## 1. 启动软件

打开桌面程序后，左侧提供以下主要入口：

- 项目
- 首页
- 数据
- 资料
- 分析
- AI 助手
- 设置

工程构建产物的可执行文件名为 `Catalyst Longevity Research.exe`，软件界面显示中文产品名称。

## 2. 最快体验方式：内置数据集

在“首页”或“数据”页面点击 **内置数据集**，可以直接选择：

1. **长期稳定性对比**：查看多个催化剂的长期性能曲线、保持率、T90 和同时间对比。
2. **T90 区间定位**：查看 T90 位于两个实测时间点之间时的区间表达和加密采样建议。
3. **长周期寿命下限**：查看测试结束仍未达到 T90 时的寿命下限和延长实验建议。
4. **实验条件差异检查**：查看不同测试温度如何触发条件检查并停止直接排名。
5. **数据质量检查**：查看重复时间点、条件缺失和条件变化如何被自动识别。

这些数据均为系统内置的模拟数据，只用于功能演示、培训和流程验证，不作为真实实验结论。

## 3. 导入自己的数据

系统支持：

- CSV `.csv`
- Excel `.xlsx`

最少需要三列：

| 催化剂 | 时间 | 性能 |
| --- | ---: | ---: |
| Catalyst A | 0 | 82 |
| Catalyst A | 20 | 78 |
| Catalyst A | 50 | 73 |
| Catalyst B | 0 | 76 |
| Catalyst B | 20 | 74 |
| Catalyst B | 50 | 72 |

常用中英文列名均可识别。

为了让不同催化剂之间的比较更可靠，建议同时提供以下实验条件：

- 温度
- GHSV 或 WHSV
- 压力
- 进料比
- 指标名称
- 数据来源

## 4. 数据检查

数据载入后，系统自动进入同一套检查流程，包括：

- 重复时间点
- 异常或无效数值
- 实验条件缺失
- 同一样品实验条件发生变化
- 不同催化剂实验条件不一致

“数据”页面会显示完整度评分，并列出发现的问题和处理建议。

## 5. 查看长期性能

“首页”集中展示：

- 催化剂数量
- 数据点数量
- 最长测试时间
- 实验条件状态
- 当前共同时间比较结果
- T90 状态
- 长期性能曲线
- 催化剂概览

曲线支持悬停查看实际观测点，并可单击聚焦某一催化剂。

## 6. 查看寿命与实验建议

进入“分析”页面后可以查看三个部分。

### 寿命指标

系统计算并保留：

- 保持率
- T95
- T90
- T80

如果阈值只知道落在两个实际采样点之间，系统显示时间区间，不把插值结果当成精确实验寿命。

### 同时间对比

系统寻找两个催化剂最近的共同实际观测时间，再进行性能比较。

如果实验条件明确不一致，系统停止输出直接领先结论；如果实验条件填写不完整，则将结果标记为参考信息。

### 实验建议

系统根据当前观测结果提示下一步实验安排，例如：

- 数据点过少时建议补充时间点；
- T90 尚未达到时建议延长测试；
- T90 位于两个时间点之间时建议在区间内增加采样；
- 首次观测已经低于阈值时建议提前首个采样时间；
- 实验条件不完整时提示补齐记录。

## 7. 整理论文资料

在“资料”页面可以导入带文本层的 PDF、TXT、Markdown、CSV 或 TSV 等资料。

系统可以识别 DOI、温度、测试时长、转化率等候选信息，并允许用户把资料条目关联到具体催化剂和时间点。只有经过人工确认的资料才会进入 AI 可用资料区。

## 8. 保存项目

项目可以保存为 `.clrproj` 文件，其中包括：

- 实验数据
- 实验条件
- 资料条目
- 催化剂和时间关联
- 人工确认状态

下次打开项目后可以继续追加实验数据和分析结果。

## 9. 导出报告

点击 **导出 PDF** 后，系统生成本地分析报告，内容包括：

- 数据检查
- 实验条件检查
- 催化剂寿命结果
- 同时间对比
- 下一步实验建议
- 资料来源与确认状态

## 10. 结果解释原则

系统只基于已有实验观测计算，不自动制造缺失实验点。

例如某催化剂测试到 100 h 时仍保持初始性能的 90% 以上，系统表达为 **T90 > 100 h** 或相应寿命下限，而不会把 100 h 直接写成精确寿命。

这一原则同样适用于两个采样点之间的阈值通过时间：系统保留区间信息，便于研究人员据此安排下一轮采样。
