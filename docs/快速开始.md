# Catalyst Longevity Analyzer — 快速开始

这个工具的目标很简单：把“催化剂随时间变化的一张表”转换成容易理解的长期表现比较。

你不需要先理解失活动力学、删失统计或排名算法。

## 最简单的使用方式：网页界面

安装界面依赖：

```bash
pip install -r requirements-ui.txt
```

启动：

```bash
streamlit run app.py
```

浏览器会自动打开分析页面。

你可以选择：

1. 上传 CSV；
2. 上传 Excel；
3. 直接在网页表格里粘贴或修改数据。

## 数据怎么准备

最少只需要三列：

| 催化剂 | 时间 | 性能 |
|---|---:|---:|
| Catalyst A | 0 | 82 |
| Catalyst A | 20 | 70 |
| Catalyst A | 50 | 58 |
| Catalyst B | 0 | 76 |
| Catalyst B | 20 | 72 |
| Catalyst B | 50 | 69 |

“性能”可以是：

- 转化率；
- 活性；
- TOF；
- 其他“数值越高代表表现越好”的连续指标。

当前软件默认同一张表中的性能列具有相同含义和量纲。

## 软件会告诉你什么

点击 **开始分析** 后，会优先展示：

- 每个催化剂的初始表现；
- 测试结束时还保留多少性能；
- 哪个催化剂更耐久；
- 两个催化剂是否发生“前期领先、后期被反超”；
- 95%、90%、80% 性能保持时间是否已经测到；
- 当前测试是不是太短，还不能给出真实寿命。

## 可选信息

如果你有误差范围，可以增加：

- `下限`
- `上限`

如果你需要保留来源，还可以增加：

- `指标`
- `数据来源`
- `paper_id`

这些都不是普通用户完成一次分析的必填项。

## 下载结果

网页中可以下载两种结果：

- **简明报告 Markdown**：适合自己阅读、发给同事或继续整理；
- **完整 JSON**：适合程序、Agent、API 或进一步自动化处理。

## 一条命令完成分析

如果不需要网页：

```bash
python -m src.catlongevity.cli examples/用户数据模板.csv
```

会生成简明报告和完整数据文件。

## 一个重要原则

软件可以帮你判断“现有数据支持什么结论”，但不会凭空补出没有测量的数据点。

例如实验做到 100 小时仍然保持在初始性能的 90% 以上，软件会告诉你“90% 保持时间至少超过 100 小时”，而不会直接把寿命写成 100 小时。
